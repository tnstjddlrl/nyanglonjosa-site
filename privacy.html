1. 개요

"냥론조사 업로더"(이하 "앱")는 유튜브 채널 냥론조사의 운영자가 자신의 채널에 영상을 올리기 위해 사용하는 개인용 도구입니다. 앱은 운영자 본인의 Google 계정으로만 로그인하며, 일반 이용자를 대상으로 서비스를 제공하지 않습니다.

2. 처리하는 정보

  • Google OAuth 인증 정보: 운영자가 앱에 권한을 허용할 때 발급되는 액세스·갱신 토큰
  • 업로드 콘텐츠: 운영자가 올리는 영상 파일과 제목·설명·태그, 운영자가 작성하는 댓글

앱은 시청자나 다른 Google 사용자의 개인정보를 수집하지 않습니다.

3. 이용 목적

위 정보는 YouTube API 서비스를 통해 운영자 채널에 영상을 업로드하고, 운영자 이름으로 댓글을 작성하는 데에만 사용합니다. 광고, 분석, 판매 등 다른 목적으로 사용하지 않습니다.

4. 보관 및 제3자 제공

  • 인증 토큰은 운영자의 컴퓨터에만 저장되며, 별도 서버로 전송하거나 보관하지 않습니다.
  • 정보를 제3자에게 제공하거나 판매하지 않습니다. 영상 업로드를 위해 Google(YouTube)에 전달되는 경우만 예외입니다.
  • 운영자가 권한을 철회하거나 토큰 파일을 삭제하면 해당 정보는 더 이상 사용되지 않습니다.

5. YouTube API 서비스 이용

이 앱은 YouTube API 서비스를 사용합니다. 앱을 사용하는 것은 YouTube 서비스 약관에 동의하는 것이며, Google의 정보 처리는 Google 개인정보처리방침을 따릅니다.

6. 권한 철회

앱에 허용한 접근 권한은 언제든지 Google 계정 보안 설정의 서드 파티 연결에서 철회할 수 있습니다.
